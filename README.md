\# 🐸 Flog Roll 🦟



奥から流れてくるハエを、カエルの舌を伸ばして捕まえるブラウザアクションゲームです。



\## 遊び方

1\. 画面をクリックするとゲームが始まります。

2\. 奥から手前に向かって飛んでくるハエを狙ってクリックします。

3\. カエルがその方向へ舌を伸ばしてハエをキャッチします。

4\. 時間経過とともにスコアが上がり、ハエを捕まえるとボーナス点が入ります。

5\. ハエを手前まで取り逃がしてしまうと\*\*ゲームオーバー\*\*です！



\## 技術スタック

\- HTML5 Canvas

\- Vanilla JavaScript
